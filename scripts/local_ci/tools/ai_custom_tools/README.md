# 任务内辅助工具

本目录说明任务内工具的用途与边界，不设置独立 runner。`custom_test` 由现有 broker 执行。Codex 创建的脚本、
输入和输出写入当前任务的 `artifacts/custom/`，不写入受信工具目录。
可用于最小复现、边界输入生成、基线与候选输出对比、IR/诊断提取、日志与性能
分析、依赖调查及证据索引；不限于测试用例。
优先复用已有工具与测试；按验证价值补充，不为已有实现机械复制断言。

通过运行时客户端请求受控执行，保留生成文件、参数、源码哈希、完整日志、退出码、
耗时和产物索引。只生成未执行的脚本不算验证；自定义工具的声明不能成为可信 receipt。

环境自修复仅限当前任务，如降低构建并行度、修正任务临时目录或重试可恢复安装。
不得修改永久分流、基础工具、架构契约、容器配方、凭据或其他任务的源码及结果。
值得保留的改进写入建议，由维护者决定是否纳入长期控制面。

复用常驻容器，任务结束清理任务目录。不能创建一次性容器，也不能以删除共享环境
或全局缓存作为通常的测试准备。异常恢复和产物发布过程中仍保留任务证据。
