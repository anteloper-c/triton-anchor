# 任务内辅助工具

本目录说明任务内复现、选测和分析，不增加另一套 runner。
Agent 可以读写任务源码、编写测试、使用 shell、准备 base 对照及安装任务内辅助依赖。
命令由统一执行服务记录，必要脚本、输入、JUnit、IR 和日志从执行开始保存到持久产物目录。

原生命令与内置工具采用相同的覆盖、报告及安装来源判据；满足后可抵扣最低检查，避免重复运行。
只生成脚本、退出 0、空报告或全部跳过不算验证。修改源码后的通过归属修改版本；
新增测试可补充原 wheel 证据，弱化原测试断言后的通过不能替代原测试。

每任务一个容器与一个非 root 用户，candidate/base/experiment 只是目录和工件版本。
任务结束先收齐并封存证据，再清理容器；任务内修复不自动变成长久环境配方。
